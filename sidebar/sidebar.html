KI für „Zu Tasks hinzufügen"

Text auf einer Webseite markieren → Rechtsklick → Zu Tasks hinzufügen. Die KI sucht die passende Liste und Stelle und trägt Titel, Fälligkeit (mit Uhrzeit) und den Link zur Seite ein.

Gesendet werden der markierte Text, Adresse und Titel der Seite sowie die Titel deiner Listen und Aufgaben.

Verbindung

Läuft über Claude Code auf diesem Rechner, also über dein Claude-Abo – kein API-Schlüssel, keine Extrakosten (zählt zum normalen Nutzungslimit). Einmal einrichten: im Projektordner native/install.sh ausführen.

Claude, OpenAI, OpenRouter … oder lokal (Ollama, LM Studio). Wird auch automatisch benutzt, wenn Claude Code fehlt. Dieser Weg ist bisher ungetestet.

„Zu Tasks hinzufügen" erscheint dann nicht im Rechtsklick-Menü. Alles andere funktioniert wie gewohnt.

Verlauf

Klick auf einen Schritt springt zu diesem Stand. Machst du nach Strg+Z etwas Neues, entsteht ein Zweig – der alte bleibt erhalten. ↶ nimmt nur diesen einen Schritt zurück, spätere bleiben. Der Verlauf bleibt auf diesem Rechner gespeichert.

    Zusammenführen: Listen und Aufgaben aus der Sicherung kommen dazu (gleiche Einträge werden überschrieben), alles andere bleibt.

    Alles ersetzen: die jetzigen Listen und Aufgaben werden durch die Sicherung ersetzt.
